# Проект: новостной сайт об инвестициях и бизнесе

Этот файл — передача контекста из чата с Claude. Читай его перед любой работой в репозитории.

## Что строим

Онлайн-медиа об инвестициях и бизнесе с фокусом на Украину. Цель — стать источником, которому доверяют.
Через 12–24 месяца на этой базе появится инвестиционная платформа: каталог проверенных проектов,
затем посредник между инвестором и проектом. Сейчас строим только медиа (MVP), но архитектура
не должна мешать платформе.

Владелец: Эльдар. Общается на русском, сайт — на украинском (основной язык), позже английский.

## Ключевые файлы

- `docs/TZ.md` — полное техзадание (11 разделов). Источник правды по требованиям.
- `design/*.dc.html` — макеты трёх страниц: `Main` (главная), `Article` (материал), `Check` (проверка).
  Это формат дизайн-канваса: обычный HTML с инлайн-стилями плюс служебные теги
  (`<x-dc>`, `<sc-for>`, `<sc-if>`, `{{переменные}}`) и данными в классе `Component.renderVals()`.
  Отдельно в браузере они не откроются — используй их как эталон разметки, отступов, цветов и текстов,
  а не как код для копирования.

## Структура сайта

4 раздела (URL на украинской версии с префиксом `/ua/`, английской — `/en/`):

1. `/ukraine/` — Инвестиции в Украину: недвижимость, промышленность, энергетика, технологии,
   military tech, агро, восстановление и госпрограммы, финансовые инструменты (ОВГЗ, фонды).
2. `/abroad/` — Инвестиции за рубежом: недвижимость, фондовые рынки, бизнес, ВНЖ за инвестиции, налоги.
3. `/checks/` — Проверки и разоблачения: проверки проектов с вердиктом, предупреждения регулятора,
   схемы мошенничества, проверки по запросу читателей.
4. `/news/` — Главные новости: Украина, мир, стартапы, дайджест недели.

Сквозные таксономии: аудитория («В Україні», «Діаспора», «Іноземцям»), формат
(новость, разбор, проверка, гайд, кейс, интервью, цифры), страна/регион, свободные теги.

## Принятые решения

- **Стек:** Next.js (App Router, SSR/ISR) + Payload CMS + PostgreSQL. Поиск — Meilisearch.
  Файлы — S3-совместимое хранилище (Cloudflare R2). CDN/WAF — Cloudflare.
- **Мультиязычность с первого дня:** `/ua/`, `/en/`, hreflang, связка переводов одного материала.
  Украинская версия — по умолчанию.
- **Сущность «Компания / проект»** в БД с первого дня (название, код ЄДРПОУ, отрасль, страна, сайт);
  материалы и проверки привязываются к ней — это основа будущего каталога.
- **Вердикты проверок (enum):** «Ризиків не знайдено», «Є питання», «Високий ризик», «Ознаки шахрайства».
  Критерий проверки имеет статус: «Гаразд» / «Питання» / «Порушення».
- **Роли:** Администратор, Главный редактор, Редактор (не публикует проверки), Автор,
  Рекламный менеджер (не может снять метку «Реклама»).
- **Статусы материала:** черновик → на редактуре → на проверке фактов → запланировано → опубликовано → в архиве.

## Правила, которые нельзя нарушать

- Реклама всегда маркируется («Реклама» / «Партнёрський матеріал» + имя заказчика). Опубликовать
  рекламный материал без метки технически невозможно.
- Перевірки публикуются только главным редактором после этапа проверки фактов.
- В рубрике military tech перед публикацией — чек-лист: никаких локаций производства,
  теххарактеристик и непубличных данных.
- Сайт не даёт инвестиционных рекомендаций: дисклеймер в конце каждого разбора и проверки.
- Учётные записи (домен, хостинг, Cloudflare, репозиторий) — на владельца.
- В MVP нет приёма денег, KYC/AML и кабинетов инвесторов.

## Состояние проекта (обновлять по ходу работы)

**Сделано (этапы 1–2):**
- Каркас: Next.js 16 + Payload 3.94 + PostgreSQL в одном приложении, docker-compose (Postgres, Meilisearch),
  Dockerfile, README, начальная миграция `src/migrations/`.
- Коллекции: Materials, Authors, Media, Sections, Rubrics, Tags, Regions, Companies, CheckRequests,
  RequestFiles, Evidence, Corrections, ErrorReports, Users, AuditLog. Globals: Homepage, SiteSettings.
- Редакционные правила — `src/collections/Materials/hooks.ts`, покрыты тестами `tests/int/editorial-rules.int.spec.ts`.
- Временный фронтенд: `/ua`, `/en`, раздел, рубрика, материал (вердикт, чек-лист, история вердикта,
  дисклеймер, метка рекламы, hreflang, OG, 301 со старых адресов).

**Технические решения, которые важно знать:**
- В URL префикс `/ua/`, в Payload и hreflang код языка `uk`. Соответствие — только в `src/i18n/config.ts`.
- `localization.fallback: true` (иначе REST без `?locale` ломается), но публичные запросы
  (`src/lib/payload.ts`) передают `fallbackLocale: false` — английская страница без перевода = 404.
- Публичные запросы идут с `overrideAccess: false`: читатель видит ровно то, что разрешает `access.read`.
- Своего статуса публикации Payload (`drafts`) не используем — свой `status`; версии включены для истории и отката.
  «Запланировано» = видно читателю, когда `publishedAt` ≤ сейчас (без cron; ISR revalidate 60 с).
- Field-level access применяется ПОСЛЕ collection-хуков: поля, которые заполняет хук (`createdBy`,
  `verdictHistory`, `previousPaths`), не закрывать через `access.update`.
- Старые адреса материалов — массив `previousPaths`, редирект 308 (`permanentRedirect`), для поисковиков равен 301.

**Не сделано / дальше:**

- Meilisearch-индексация (хуки afterChange) и страница поиска с украинской морфологией.
- Формы: подписка (double opt-in), «Перевірте проєкт» (Turnstile, файлы до 10 МБ), «Повідомити про помилку».
- Telegram-кнопка в админке, сервис рассылок, аналитика + cookie-баннер, sitemap / Google News sitemap / RSS,
  Schema.org (NewsArticle, ClaimReview), страница «Виправлення», служебные страницы.
- Предпросмотр (desktop/mobile), 2FA (в Payload нет из коробки — нужен плагин или своя реализация),

4. Интеграции MVP: Telegram-автопостинг, сервис рассылок, аналитика, sitemap/RSS/Schema.org.
5. Критерии приёмки MVP — раздел 11 в `docs/TZ.md`.
